--------------------------------------------------------------------------------
CAC KHOI DUNG CHUNG
--------------------------------------------------------------------------------

DynamicConv
  CondConv co routing: GAP -> Linear -> sigmoid -> tron num_experts=4 kernel.
  File: nn/modules/addModules/DynamicConvolution.py

C3k2_DynamicConv
  Thay C3k2. Bottleneck ben trong dung DynamicConv thay vi Conv thuong.

CARAFE
  Upsample theo noi dung, x2. Thay nn.Upsample nearest.
  File: nn/modules/addModules/Variants.py

HyperACE
  Fusion da ti le kieu YOLOv13.
  Luon co 2 nhom nhanh:
    - High-order: 2 x C3AH (hypergraph)
    - Low-order: DSC3k (neu dsc3k=True) hoac DSBottleneck (neu False)
  File: nn/modules/block.py

HyperACE_Dyn
  Cung API va cung wiring voi HyperACE.
  High-order van la 2 x C3AH.
  Low-order doi thanh C3k_DynamicConv (use_c3k=True) hoac Bottleneck_DynamicConv.
  File: nn/modules/block.py

FullPAD_Tunnel
  Cong residual: x0 + gate * x1. Gate khoi tao 0.

DownsampleConv
  AvgPool2d + Conv 1x1, dung cho tunnel xuong ti le.


Args HyperACE / HyperACE_Dyn trong YAML:
  [512, 4, True, True, 0.25, 1, "both"]

  c2 = 512
  num_hyperedges = 4   (scale n: parse_model nhan 0.5 -> 2 hyperedges)
  c3k / dsc3k = True
  shortcut = True
  e1 = 0.25
  e2 = 1
  context = "both"

  Input layers: [4, 6, 10] = P3, P4, P5 cua backbone.


Trong HyperACE / HyperACE_Dyn luon co CA HAI nhom nhanh.
Ideal va A4 KHAC nhau o nhom low-order, KHONG khac o high-order:

  Ideal / A3: low-order = C3k_DynamicConv   (module HyperACE_Dyn)
  A4:         low-order = DSC3k              (module HyperACE)

--------------------------------------------------------------------------------
A3 — yolo26-ablate-hace.yaml (Dyn + HyperACE_Dyn + FullPAD, khong CARAFE)
--------------------------------------------------------------------------------

Doi head sang kieu YOLOv13 FullPAD. Upsample van nearest.

Head:
  1. HyperACE_Dyn([4,6,10])
     high-order = 2 x C3AH
     low-order  = C3k_DynamicConv
     4 edges (YAML), e1=0.25 -> layer 11
  2. Upsample nearest (12) + DownsampleConv (13) tu layer 11
  3. FullPAD tunnels khoi tao:
       [6,11]  -> tunnel 14 (P4 + HyperACE)
       [4,12]  -> tunnel 15 (P3 + up)
       [10,13] -> tunnel 16 (P5 + down)
  4. PAN: upsample -> Concat tunnel -> C3k2_DynamicConv,
     roi tunnel lai voi HyperACE / feature da enhance
  5. Detect lay [25, 29, 33]

Muc dich: do HyperACE_Dyn + FullPAD khi chua co CARAFE.
